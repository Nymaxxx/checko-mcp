# Методология аудита физического лица

> **Правовое основание.** Методология основана на анализе публично раскрытых сведений из государственных реестров и официальных источников. Сбор и обработка персональных данных допускается только при наличии законного основания в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных». Результаты аудита предназначены для внутреннего использования и не подлежат передаче третьим лицам без согласия субъекта или иного законного основания.

---

## Принципы

- **От общего к частному**: сначала собрать всю структуру активов, потом углубляться в каждый элемент
- **Хронология важна**: изменения в динамике говорят больше, чем текущий срез
- **Аномалия — это отклонение от нормы**: сравнивай с отраслью, размером компании, датами событий
- **Связи важнее одиночных фактов**: один директор в двух компаниях — норма; один директор в 30 компаниях-однодневках — красный флаг

## Этап 1. Сбор базового профиля

**Инструмент:** `get_person(inn=...)`

### Что получаем
- Все организации, где физлицо является **руководителем** (`Руковод[]`)
- Все организации, где физлицо является **учредителем** (`Учред[]`)
- Все зарегистрированные **ИП** (`ИП[]`)
- **Товарные знаки** (`ТоварЗнак[]`)
- **Банкротства** из ЕФРСБ (`ЕФРСБ[]`)
- **Реестр недобросовестных поставщиков** (`НедобПост`)
- **Массовый руководитель/учредитель** (`МассРуковод`, `МассУчред`)
- **Санкции** (`Санкции`, `СанкцииСтраны[]`)

### Что фиксируем
- Общее количество организаций (действующих / ликвидированных)
- Общее количество ИП (действующих / прекращённых)
- Есть ли красные флаги сразу (банкротства, санкции, НДП)
- Временной диапазон активности (самая ранняя дата регистрации — текущий момент)

## Этап 3. Финансовый анализ

**Инструмент:** `get_finances(inn=... [, extended=true])`

Для каждой **действующей** организации и ИП с ненулевой налоговой нагрузкой (из `get_company → Налоги`).

### Что анализируем

#### Выручка и прибыль
- Динамика выручки год к году (строка 2110)
- Чистая прибыль (строка 2400) — убытки несколько лет подряд = риск
- Рентабельность: прибыль / выручка
- Резкие скачки или обрывы выручки → когда и почему?

#### Баланс
- Соотношение активов и обязательств
- Рост краткосрочных обязательств (строка 1500) без роста активов
- Отрицательный капитал (строка 1300 < 0) = технически банкрот

#### Налоговая нагрузка
- Сравнить уплаченные налоги (из `Налоги.СведУпл`) с выручкой
- Нулевые налоги при ненулевом балансе — сигнал
- Резкое снижение налогов в конкретный год

#### Аномалии в финансах
- Выручка растёт, прибыль падает → деньги уходят (зарплаты? вывод?)
- Активы исчезают в год ликвидации/реорганизации
- Резкий рост внеоборотных активов без понятного обоснования

## Этап 4. Правовые риски

**Инструменты:** `get_legal_cases`, `get_fedresurs`, `get_bankruptcy_messages`

### Арбитражные дела (`get_legal_cases`)

Запускать для каждой организации, особенно:
- `role=defendant` — дела, где компания ответчик (долги, иски)
- `actual=true` — только актуальные
- `active=true` — только незавершённые

**Что ищем:**
- Регулярные иски о взыскании долгов (кредиторы, ФНС, ПФР)
- Дела о банкротстве (А40-XXXXXX по статье 127-ФЗ)
- Оспаривание сделок — возможный вывод активов
- Высокая общая сумма исков (`ОбщСуммИск`) относительно размера компании

### Федресурс (`get_fedresurs`)

**Что ищем:**
- `CreditorIntentionGoToCourt` — кредиторы готовятся подать на банкротство
- `PledgeAgreement` — заложено имущество
- `LiquidationMessage` — начата ликвидация
- Любые сообщения за последние 6–12 месяцев

### ЕФРСБ (`get_bankruptcy_messages`)

**Что ищем:**
- Введена любая процедура банкротства
- Назначен арбитражный управляющий
- Реализация имущества

## Этап 5. Хронологический анализ

**Инструмент:** `get_timeline(inn=...)`

Запускать для самого физлица (по ИНН) и для ключевых организаций.

### Что строим

Таблицу событий с флагами:

| Дата | Субъект | Событие | Флаг |
|------|---------|---------|------|
| | | | |

### Паттерны, которые ищем

**Переброска активов:**
- Создание новой компании → смена директора в старой → ликвидация старой
- Смена учредителей перед крупным судебным делом
- Вывод имущества через реорганизацию

**Признаки кризиса:**
- Смена директора + смена адреса в один период
- Внесение изменений в устав перед делом о банкротстве
- Цепочка: иск → смена учредителя → ликвидация

**Периодичность активности:**
- Регулярное создание и ликвидация ИП (схема дробления)
- Параллельное существование нескольких компаний с похожим ОКВЭД

## Этап 6. Анализ связей

На основе данных из всех этапов строим карту связей:

### Связанные лица
- Кто ещё является учредителем тех же компаний?
- Кто является директором там, где субъект — учредитель?
- Есть ли пересечения адресов между компаниями субъекта?

### Цепочки контроля
- Компании субъекта как учредители других компаний (`СвязУчред` в `get_company`)
- ИП субъекта как контрагент его же компаний (схема аутсорса себе)

### Что проверить дополнительно
- Директора каждой из компаний → `get_person` по их ИНН
- Другие учредители → `get_person` по их ИНН

## Этап 7. Итоговая оценка

### Система оценки риска

| Категория | Вес | Факторы |
|---|---|---|
| Правовые риски | Высокий | Активные судебные дела, ЕФРСБ, НДП |
| Финансовые аномалии | Высокий | Отрицательный капитал, резкие изменения |
| Структурные риски | Средний | Много ликвидированных компаний, массовые адреса |
| Санкции | Критический | Прямые или через учредителей |
| Поведенческие паттерны | Средний | Хронологические аномалии |

### Уровни риска

- **Низкий**: нет красных флагов, устойчивая деятельность
- **Умеренный**: 1–2 жёлтых флага, требует мониторинга
- **Высокий**: красные флаги в нескольких категориях
- **Критический**: санкции, банкротство, НДП, активные иски одновременно
