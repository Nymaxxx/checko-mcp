# Аудит физического лица — структура папки

Инструменты для проведения полного аудита активов физического лица через Checko API.

> **Правовой дисклеймер.** Инструменты в этой папке предназначены исключительно для работы с публично раскрытыми сведениями из государственных реестров (ЕГРЮЛ, ЕГРИП) в целях законной проверки контрагентов. Использование данных о физических лицах без законного основания может нарушать требования Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных». Ответственность за соответствие деятельности действующему законодательству несёт пользователь. Отчёты, содержащие персональные данные, не должны публиковаться в открытом доступе — папка `reports/` исключена из git через `.gitignore`.

## Файлы

| Файл | Описание |

## Быстрый старт

1. Получить ИНН физлица (12 цифр)
2. Скопировать `audit-template.md` → `reports/<ФИО>-<дата>.md`
3. Следовать этапам из `methodology.md`
4. Заполнять шаблон по мере сбора данных
5. Свериться с `anomaly-checklist.md` при интерпретации

## Необходимые инструменты Checko MCP

- `profile(identifier=<ИНН>, kind="person")` — отправная точка
- `profile` — по каждой связанной организации
- `profile` — по каждому ИП
- `get_finances` — финансовая отчётность
- `get_legal_cases` — судебные дела
- `get_timeline` — хронология изменений
- `get_fedresurs` — залоги, намерения о банкротстве
- `get_bankruptcy_messages` — банкротные процедуры
