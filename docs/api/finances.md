# /finances — Финансовая отчётность

Финансовая отчётность российских организаций: данные Росстата (2011–2018) и ГИР БО ФНС (2019–н.в.), а также ссылки на официальные PDF-отчёты с подписью ФНС.

## Запрос

```
GET https://api.checko.ru/v2/finances?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/finances?key=API_KEY&ogrn={ОГРН}&extended=true
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации |
| `inn` | string | один из | ИНН организации. При нескольких совпадениях — головная |
| `extended` | string | нет | `true` — расширенная версия отчётности (объекты строк вместо чисел) |

## Расширенный формат (`extended=true`)

Строки отчётности возвращаются как объекты:

```json
{
  "data": {
    "2022": {
      "1100": {
        "СумОтч": 85000000,
        "СумПрдщ": 80000000,
        "СумПрдшв": 75000000
      },
      "3200": {
        "Итог": 20000000,
        "ДобКапитал": 5000000,
        "НераспПриб": 10000000,
        "РезКапитал": 3000000,
        "УстКапитал": 2000000,
        "СобВыкупАкц": 0
      },
      "4300": {
        "СумОтч": 1500000,
        "СумПред": 1200000
      }
    }
  }
}
```

## Коды строк отчётности

Полный справочник кодов строк доступен для скачивания: https://checko.ru/integration/api/datasets

Основные коды:

| Код | Строка |
|-----|--------|
| `1100` | Итого по разделу I (Внеоборотные активы) |
| `1200` | Итого по разделу II (Оборотные активы) |
| `1600` | Баланс (актив) |
| `1300` | Итого по разделу III (Капитал и резервы) |
| `1400` | Итого по разделу IV (Долгосрочные обязательства) |
| `1500` | Итого по разделу V (Краткосрочные обязательства) |
| `1700` | Баланс (пассив) |
| `2110` | Выручка |
| `2200` | Прибыль/убыток от продаж |
| `2300` | Прибыль/убыток до налогообложения |
| `2400` | Чистая прибыль/убыток |
