# /contracts — Государственные контракты (44-ФЗ / 223-ФЗ)

Контракты с участием организации или ИП по 44-ФЗ и 94-ФЗ, договоры по 223-ФЗ. **API возвращает контракты строго по одному закону за вызов** — параметр `law` обязателен.

## Запрос

```
GET https://api.checko.ru/v2/contracts?key=API_KEY&inn={ИНН}&law=44
GET https://api.checko.ru/v2/contracts?key=API_KEY&ogrn={ОГРН}&law=223
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации |
| `inn` | string | один из | ИНН организации |
| `law` | string | **да** | Закон о госзакупках: `44` (44-ФЗ), `94` (94-ФЗ) или `223` (223-ФЗ) |
| `role` | string | нет | Роль: `customer` (заказчик) или `supplier` (поставщик) |
| `sort` | string | нет | Сортировка: `date` / `-date` по дате, `price` / `-price` по сумме |
| `limit` | integer | нет | Записей на страницу (по умолчанию и максимум — 100) |
| `page` | integer | нет | Номер страницы |

> Чтобы получить контракты по нескольким законам — нужны отдельные вызовы с `law=44`, `law=94`, `law=223` и объединение результатов на стороне клиента.
>
> `sort=-price` возвращает крупнейшие контракты первыми — это быстрее, чем выгружать все страницы.

## Формат ответа

```json
{
  "company": {
    "ОГРН": "...", "ИНН": "...", "КПП": "...",
    "НаимСокр": "...", "Статус": "Действует"
  },
  "data": {
    "ЗапВсего": 150,
    "СтрВсего": 2,
    "СтрТекущ": 1,
    "Записи": [
      {
        "Номер": "0372200074223000076",
        "Тип": "44-ФЗ",
        "ДатаЗакл": "2023-03-15",
        "ДатаИсп": "2023-12-31",
        "Цена": 5000000,
        "Заказчик": {
          "ИНН": "...",
          "НаимСокр": "...",
          "НаимПолн": "..."
        },
        "Предмет": "Поставка оборудования"
      }
    ]
  },
  "meta": { "status": "ok", "today_request_count": 1, "balance": 1000 }
}
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `data.ЗапВсего` | Общее количество контрактов |
| `data.Записи[].Номер` | Реестровый номер контракта |
| `data.Записи[].Тип` | `44-ФЗ` или `223-ФЗ` |
| `data.Записи[].ДатаЗакл` | Дата заключения |
| `data.Записи[].ДатаИсп` | Дата исполнения (срок) — v2.2 |
| `data.Записи[].Цена` | Цена контракта, руб. |
| `data.Записи[].Заказчик` | Заказчик (ИНН, наименование) |
| `data.Записи[].Предмет` | Предмет контракта |
