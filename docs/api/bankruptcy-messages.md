# /bankruptcy-messages — Записи ЕФРСБ (v2.4)

Записи Единого федерального реестра сведений о банкротстве (ЕФРСБ) по юридическим и физическим лицам. Добавлен в версии 2.4 (февраль 2026).

## Запрос

```
GET https://api.checko.ru/v2/bankruptcy-messages?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/bankruptcy-messages?key=API_KEY&ogrn={ОГРН}&date_from=2020-01-01&date_to=2024-12-31
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации или ОГРНИП ИП |
| `inn` | string | один из | ИНН организации, ИП или физлица |
| `date_from` | string | нет | Дата публикации от (YYYY-MM-DD) |
| `date_to` | string | нет | Дата публикации до (YYYY-MM-DD) |
| `limit` | integer | нет | Записей на страницу (макс. 100) |
| `page` | integer | нет | Номер страницы |
| `sort` | string | нет | `date` или `-date` |

## Примеры

```
GET https://api.checko.ru/v2/bankruptcy-messages?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/bankruptcy-messages?key=API_KEY&ogrn={ОГРН}&date_from=2020-01-01&date_to=2024-12-31
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `data.ЗапВсего` | Общее количество записей |
| `data.Записи[].GUID` | GUID записи |
| `data.Записи[].URL` | Ссылка на страницу записи на Федресурсе |
| `data.Записи[].Дата` | Дата публикации |
| `data.Записи[].Тип` | Тип записи (код) |
| `data.Записи[].ТипНаим` | Описание типа записи |
| `data.Записи[].НомерДела` | Номер судебного дела (если привязана) |
| `data.Записи[].Суд` | Наименование суда |
| `data.Записи[].РешенСуда` | Резолютивная часть решения суда |

## Справочник типов записей ЕФРСБ

Полный перечень: https://checko.ru/uploads/datasets/bankruptcy_message_types.xlsx

Основные типы:

| Тип | Описание |
|-----|----------|
| `BankruptcyIntroduced` | Введена процедура банкротства |
| `BankruptcyCompleted` | Процедура банкротства завершена |
| `ArbitrageManagerAppointed` | Назначен арбитражный управляющий |
| `ClaimsAccepted` | Требования кредиторов включены в реестр |
| `PropertySale` | Продажа имущества должника |
