# /search — Поиск компаний и ИП

Поиск организаций в ЕГРЮЛ. API требует одновременно три обязательных параметра: критерий поиска `by`, тип объекта `obj` и строку `query`.

> ⚠️ **Важно.** Эндпоинт **не предназначен** для прямой выборки по ОГРН/ИНН — для этого используйте `/company`. `/search` стабильно работает только для текстового поиска по названию и поиска по коду ОКВЭД-2.

## Запрос

```
GET https://api.checko.ru/v2/search?key=API_KEY&by={критерий}&obj={тип}&query={строка}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `by` | string | **да** | Критерий поиска. Проверены: `name` (по наименованию), `okved` (по коду ОКВЭД-2) |
| `obj` | string | **да** | Тип объекта. Сейчас стабильно работает: `org` (юридическое лицо) |
| `query` | string | **да** | Строка поиска: название (для `by=name`) или код (для `by=okved`) |
| `region` | string | нет | Код региона РФ (например, `77` — Москва) |
| `codes` | string | нет | `all` — искать также по дополнительным кодам ОКВЭД-2 (v2.4) |
| `date_from` | string | нет | Дата регистрации от (YYYY-MM-DD) |
| `date_to` | string | нет | Дата регистрации до (YYYY-MM-DD) |
| `limit` | integer | нет | Количество результатов на страницу (макс. 100) |
| `page` | integer | нет | Номер страницы |

## Примеры запросов

```
# Поиск по названию
GET https://api.checko.ru/v2/search?key=API_KEY&by=name&obj=org&query={название}

# Поиск по коду ОКВЭД-2 в регионе
GET https://api.checko.ru/v2/search?key=API_KEY&by=okved&obj=org&query=62.01&region=77&codes=all
```

### Поля `data`

| Поле | Описание |
|------|----------|
| `НайденоВсего` / `ЗапВсего` | Общее число найденных записей |
| `СтрВсего` | Количество страниц |
| `СтрТекущ` | Текущая страница |
| `Записи[].ОГРН` | ОГРН (или ОГРНИП для ИП) |
| `Записи[].ИНН` | ИНН |
| `Записи[].КПП` | КПП (только для юрлиц) |
| `Записи[].НаимСокр` | Сокращённое наименование |
| `Записи[].НаимПолн` | Полное наименование |
| `Записи[].ДатаРег` | Дата регистрации |
| `Записи[].Статус` | Статус |
| `Записи[].РегионКод` | Код региона РФ |
| `Записи[].ЮрАдрес` | Юридический адрес |
| `Записи[].ОКВЭД` | Основной код ОКВЭД-2 |

## Особенности

- **HTTP 400 не списывает баланс** — API возвращает ошибку валидации до вычета.
- Для поиска юрлица по ОГРН/ИНН вызывайте `/company` — `/search` для этого не предназначен.
- Поиск по физлицам через `/search` не реализован: используйте `/person?inn=…`.
