# /search — Поиск компаний и ИП

Поиск организаций в ЕГРЮЛ. API требует одновременно три обязательных параметра: критерий поиска `by`, тип объекта `obj` и строку `query`.

> ⚠️ **Важно.** Эндпоинт **не предназначен** для прямой выборки по ОГРН/ИНН — для этого используйте `/company`. `/search` стабильно работает только для текстового поиска по названию и поиска по коду ОКВЭД-2.

## Запрос

```
GET https://api.checko.ru/v2/search?key=API_KEY&by={критерий}&obj={тип}&query={строка}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `by` | string | **да** | Критерий поиска: `name` — по наименованию организации или ФИО предпринимателя, `founder-name` — по ФИО учредителя или наименованию компании-учредителя, `leader-name` — по ФИО руководителя, `okved` — по коду ОКВЭД-2 основного вида деятельности, `reg-date` — по дате регистрации, `upd-date` — по дате обновления выписки |
| `obj` | string | **да** | Область поиска: `org` — организации, `ent` — индивидуальные предприниматели |
| `query` | string | **да** | Текст запроса. Минимум 4 символа для поиска по наименованию или ФИО. Для `by=reg-date` и `by=upd-date` — дата в формате YYYY-MM-DD |
| `region` | string | нет | Код региона РФ, 2 цифры (например, `77` — Москва) |
| `okved` | string | нет | Фильтр по основному коду ОКВЭД-2. Не применяется при `by=okved` |
| `opf` | string | нет | Код организационно-правовой формы по ОКОПФ, 2 или 5 цифр. Не применяется при `by=name` и при `obj=ent` |
| `active` | string | нет | `true` — только действующие организации и ИП |
| `codes` | string | нет | `all` — при `by=okved` искать также по дополнительным кодам ОКВЭД-2 (v2.4) |
| `limit` | integer | нет | Количество результатов на страницу (по умолчанию и максимум — 100) |
| `page` | integer | нет | Номер страницы |

> У метода **нет** параметров `date_from` и `date_to`. Поиск по дате регистрации выполняется через `by=reg-date` с датой в `query`.
>
> По наименованию отдаётся не более 100 записей, отсортированных по релевантности; для остальных критериев количество результатов не ограничено, сортировка — по ОГРН или ОГРНИП.

## Примеры запросов

```
# Поиск по названию
GET https://api.checko.ru/v2/search?key=API_KEY&by=name&obj=org&query={название}

# Поиск по коду ОКВЭД-2 в регионе
GET https://api.checko.ru/v2/search?key=API_KEY&by=okved&obj=org&query=62.01&region=77&codes=all

# Все организации, где человек указан учредителем
GET https://api.checko.ru/v2/search?key=API_KEY&by=founder-name&obj=org&query={ФИО}

# Организации, зарегистрированные в конкретную дату
GET https://api.checko.ru/v2/search?key=API_KEY&by=reg-date&obj=org&query=2021-12-09
```

### Поля `data`

| Поле | Описание |
|------|----------|
| `НайденоВсего` / `ЗапВсего` | Общее число найденных записей |
| `СтрВсего` | Количество страниц |
| `СтрТекущ` | Текущая страница |
| `Записи[].ОГРН` | ОГРН (или ОГРНИП для ИП) |
| `Записи[].ИНН` | ИНН |
| `Записи[].КПП` | КПП (только для юрлиц) |
| `Записи[].НаимСокр` | Сокращённое наименование |
| `Записи[].НаимПолн` | Полное наименование |
| `Записи[].ДатаРег` | Дата регистрации |
| `Записи[].Статус` | Статус |
| `Записи[].РегионКод` | Код региона РФ |
| `Записи[].ЮрАдрес` | Юридический адрес |
| `Записи[].ОКВЭД` | Основной код ОКВЭД-2 |

## Особенности

- **HTTP 400 не списывает баланс** — API возвращает ошибку валидации до вычета.
- Для поиска юрлица по ОГРН/ИНН вызывайте `/company` — `/search` для этого не предназначен.
- Поиск по физлицам через `/search` не реализован: используйте `/person?inn=…`.
