# /entrepreneur — Данные ЕГРИП по индивидуальному предпринимателю

Сведения об индивидуальном предпринимателе из ЕГРИП: регистрационные данные, ОКВЭД, лицензии, налоги, особые режимы, факторы риска.

## Запрос

```
GET https://api.checko.ru/v2/entrepreneur?key=API_KEY&ogrn={ОГРНИП}
GET https://api.checko.ru/v2/entrepreneur?key=API_KEY&inn={ИНН}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРНИП предпринимателя, 15 цифр. **Параметр называется `ogrn`, не `ogrnip`** |
| `inn` | string | один из | ИНН физического лица (12 цифр) |
| `okpo` | string | нет | Код ОКПО |
| `source` | string | нет | `true` — вернуть исходные XML-данные ЕГРИП |

> Необходимо указать хотя бы один из: `ogrn`, `inn`, `okpo`.
>
> Если ИНН соответствует нескольким предпринимателям — так бывает, когда человек прекращал
> и заново начинал деятельность, — вернётся последний зарегистрированный.

## Примеры

```

```

## Ключевые блоки `data`

| Блок | Описание |
|------|----------|
| `ОГРНИП`, `ИНН` | Идентификаторы |
| `ФИО`, `Тип` | ФИО и тип ИП |
| `ДатаРег`, `Статус`, `ДатаПрекращ` | Регистрационный статус |
| `ЭконДеят`, `ДопЭконДеят` | Основной и дополнительные ОКВЭД |
| `РегионКод` | Регион регистрации |
| `Налоги` | Налоговые платежи и особые режимы (УСН, ЕНВД и т.д.) — v2.3 |
| `Лицензии` | Лицензии с датами |
| `ТоварЗнак` | Товарные знаки (Роспатент) |
| `ЕФРСБ` | Сообщения реестра банкротств |
| `ТекФНС` | Текущий орган ФНС |
| `МСП` | Реестр МСП |
| `НедобПост` | Реестр недобросовестных поставщиков |
| `МассРуковод`, `МассУчред` | Массовый руководитель/учредитель (ФНС) |
| `Санкции`, `СанкцииСтраны` | Санкционные списки |

## Примечание по `source_data`

При `source=true` возвращает XML-данные ЕГРИП в виде JSON. Формат соответствует официальным схемам ФНС.
