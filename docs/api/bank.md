# /bank — Банки и кредитные организации

Информация о банках и кредитных организациях РФ по БИК.

## Запрос

```
GET https://api.checko.ru/v2/bank?key=API_KEY&bic={БИК}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `bic` | string | да | БИК банка или кредитной организации (9 цифр) |

## Пример

```
GET https://api.checko.ru/v2/bank?key=API_KEY&bic={БИК}
```

## Формат ответа

```json
{
  "data": {
    "БИК": "XXXXXXXXX",
    "Наим": "НАИМЕНОВАНИЕ БАНКА",
    "НаимАнгл": "BANK NAME",
    "Адрес": "...",
    "Тип": "Банк",
    "КорСчет": {
      "Номер": "XXXXXXXXXXXXXXXXXXXX",
      "Дата": "YYYY-MM-DD"
    },
    "Счета": [
      {
        "Номер": "XXXXXXXXXXXXXXXXXXXX",
        "Дата": "YYYY-MM-DD",
        "Тип": "Корреспондентский счёт"
      }
    ]
  },
  "meta": { "status": "ok", "today_request_count": 1, "balance": 1000 }
}
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `data.БИК` | БИК банка |
| `data.Наим` | Наименование на русском |
| `data.НаимАнгл` | Наименование на английском |
| `data.Адрес` | Адрес организации |
| `data.Тип` | Тип организации (Банк, НКО и т.д.) |
| `data.КорСчет.Номер` | Номер корреспондентского счёта |
| `data.КорСчет.Дата` | Дата открытия корсчёта |
| `data.Счета[]` | Все счета (номер, дата, тип) |
