# /legal-cases — Арбитражные дела

Арбитражные дела с участием организаций и индивидуальных предпринимателей. Данные Федеральных арбитражных судов (Росстат, задержка ~1–2 недели).

## Запрос

```
GET https://api.checko.ru/v2/legal-cases?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/legal-cases?key=API_KEY&ogrn={ОГРН}&role=defendant
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации или ОГРНИП ИП |
| `inn` | string | один из | ИНН организации или ИП |
| `role` | string | нет | Роль: `plaintiff` (истец) или `defendant` (ответчик) |
| `actual` | string | нет | `true` — только актуальные дела (без отклонённых, прекращённых) — v2.3 |
| `active` | string | нет | `true` — только активные (незавершённые) дела — v2.3 |
| `date_from` | string | нет | Дата возбуждения от (YYYY-MM-DD) |
| `date_to` | string | нет | Дата возбуждения до (YYYY-MM-DD) |
| `claim_amount_from` | number | нет | Минимальная сумма иска, руб. — v2.3 |
| `claim_amount_to` | number | нет | Максимальная сумма иска, руб. — v2.3 |
| `limit` | integer | нет | Записей на страницу (по умолчанию 100, макс. 100) |
| `page` | integer | нет | Номер страницы |
| `sort` | string | нет | `date` — по возрастанию, `-date` — по убыванию даты возбуждения |

## Примеры

```
GET https://api.checko.ru/v2/legal-cases?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/legal-cases?key=API_KEY&ogrn={ОГРН}&role=defendant
GET https://api.checko.ru/v2/legal-cases?key=API_KEY&inn={ИНН}&date_from=2023-04-03&date_to=2023-04-07
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `data.ЗапВсего` | Общее количество дел |
| `data.СтрВсего` | Количество страниц |
| `data.СтрТекущ` | Текущая страница |
| `data.ОбщСуммИск` | Общая сумма исков по всем делам, руб. (v2.3) |
| `data.Записи[].Номер` | Номер дела |
| `data.Записи[].UUID` | UUID дела |
| `data.Записи[].СтрКАД` | Ссылка в Картотеке арбитражных дел |
| `data.Записи[].Дата` | Дата возбуждения |
| `data.Записи[].Суд` | Наименование суда |
| `data.Записи[].Ист[]` | Список истцов (ИНН, Наим, Адрес) |
| `data.Записи[].Ответ[]` | Список ответчиков (ИНН, Наим, Адрес) |
| `data.Записи[].СуммИск` | Сумма иска, руб. |
