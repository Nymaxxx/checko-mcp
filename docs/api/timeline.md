# /timeline — История изменений (v2.4)

История основных изменений организаций, ИП и аффилированных физических лиц. Добавлен в версии 2.4 (февраль 2026).

## Запрос

```
GET https://api.checko.ru/v2/timeline?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/timeline?key=API_KEY&ogrn={ОГРН}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации или ОГРНИП ИП |
| `inn` | string | один из | ИНН организации, ИП или физлица |

> Для физического лица укажите **ИНН** — это даст полную историю.  
> При указании ОГРНИП — история только за период действия конкретного ИП.

## Примеры

```
GET https://api.checko.ru/v2/timeline?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/timeline?key=API_KEY&ogrn={ОГРН}
```

## Формат ответа

```json
{
  "company": {
    "ОГРН": "...", "ИНН": "...", "КПП": "...",
    "НаимСокр": "...", "Статус": "Действующая"
  },
  "entrepreneur": null,
  "person": null,
  "data": [
    { "Дата": "2024-11-15", "Событие": "Смена руководителя" },
    { "Дата": "2023-06-01", "Событие": "Изменение юридического адреса" },
    { "Дата": "2022-03-10", "Событие": "Внесение изменений в устав" }
  ],
  "meta": { "status": "ok", "today_request_count": 1, "balance": 1000 }
}
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `company` | Организация (если запрос по ОГРН/ИНН юрлица) |
| `entrepreneur` | ИП (если запрос по ОГРНИП/ИНН предпринимателя) |
| `person` | Физлицо (если запрос по ИНН физлица) |
| `data[].Дата` | Дата события |
| `data[].Событие` | Описание события |
