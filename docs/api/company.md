# /company — Данные ЕГРЮЛ по организации

Сведения о юридическом лице из ЕГРЮЛ: основные данные, руководители, учредители, контакты, лицензии, налоги, реестр МСП, факторы риска, аффилированные лица.

## Запрос

```
GET https://api.checko.ru/v2/company?key=API_KEY&ogrn={ОГРН}
GET https://api.checko.ru/v2/company?key=API_KEY&inn={ИНН}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации (13 цифр) |
| `inn` | string | один из | ИНН организации (10 цифр). При совпадении нескольких (филиалы) — возвращается головная |
| `okpo` | string | нет | Код ОКПО |
| `source` | string | нет | `true` — вернуть исходные XML-данные ЕГРЮЛ |

> Необходимо указать хотя бы один из: `ogrn`, `inn`, `okpo`.

## Примеры

```
GET https://api.checko.ru/v2/company?key=API_KEY&ogrn={ОГРН}
GET https://api.checko.ru/v2/company?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/company?key=API_KEY&ogrn={ОГРН}&source=true
```

## Ключевые блоки `data`

| Блок | Описание |
|------|----------|
| `ОГРН`, `ИНН`, `КПП`, `ОКПО` | Идентификаторы |
| `НаимСокр`, `НаимПолн`, `НаимАнгл` | Наименования |
| `ДатаРег`, `Статус`, `ДатаЛикв` | Регистрационный статус |
| `ОргПравФорм` | Организационно-правовая форма |
| `ЭконДеят`, `ДопЭконДеят` | Основной и дополнительные ОКВЭД |
| `РегионКод`, `ЮрАдрес` | Адрес |
| `Руковод` | Текущий руководитель |
| `Учред` | Учредители: РФ, юрлица (РосОрг/ИнОрг), физлица |
| `Капитал` | Уставный/складочный/паевой капитал |
| `Налоги` | Налоговые обязательства и задолженности |
| `МСП` | Реестр МСП (категория, дата включения) |
| `Лицензии` | Лицензии с датами действия |
| `ТоварЗнак` | Товарные знаки (Роспатент) |
| `ЕФРСБ` | Сообщения реестра банкротств |
| `ТекФНС` | Текущий орган ФНС |
| `МассАдрес` | ОГРН организаций с тем же юрадресом (v2.3) |
| `Обрем` | Обременения и залоги долей участников (v2.3) |
| `НедобПост` | Реестр недобросовестных поставщиков |
| `МассРуковод`, `МассУчред` | Массовый руководитель/учредитель (ФНС) |
| `НелегалФин` | Признак нелегальной деятельности (ЦБ РФ) |
| `Санкции`, `СанкцииСтраны` | Санкционные списки |

## Блок `source_data`

Возвращается только при параметре `source=true`. Содержит полный XML-ответ ЕГРЮЛ, преобразованный в JSON. Формат описан в [официальной документации ФНС](https://checko.ru/uploads/EGRUL_2023.docx).
