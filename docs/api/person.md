# /person — Данные по физическому лицу

Информация о физическом лице по ИНН: связи с организациями и ИП, товарные знаки, банкротства, реестр недобросовестных поставщиков, массовые показатели ФНС, санкции.

## Запрос

```
GET https://api.checko.ru/v2/person?key=API_KEY&inn={ИНН}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `inn` | string | да | ИНН физического лица (12 цифр) |

## Пример

```
GET https://api.checko.ru/v2/person?key=API_KEY&inn={ИНН}
```

## Ключевые блоки `data`

| Блок | Описание |
|------|----------|
| `ИНН`, `ФИО` | Идентификатор и ФИО |
| `Руковод[]` | Организации, в которых физлицо является руководителем |
| `Учред[]` | Организации, в которых физлицо является учредителем |
| `ИП[]` | ИП, зарегистрированные на физлицо |
| `ТоварЗнак[]` | Товарные знаки (Роспатент) |
| `ЕФРСБ[]` | Сообщения реестра банкротств |
| `НедобПост` | Признак включения в реестр недобросовестных поставщиков |
| `НедобПостЗап[]` | Записи реестра НДП |
| `МассРуковод`, `МассУчред` | Массовый руководитель/учредитель по данным ФНС |
| `Санкции`, `СанкцииСтраны[]` | Санкционные списки и страны |
