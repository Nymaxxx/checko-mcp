# /inspections — Проверки

Сведения о проверках (плановых и внеплановых) в отношении организации или ИП.

## Запрос

```
GET https://api.checko.ru/v2/inspections?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/inspections?key=API_KEY&ogrn={ОГРН}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации |
| `inn` | string | один из | ИНН организации |
| `limit` | integer | нет | Записей на страницу |
| `page` | integer | нет | Номер страницы |

## Формат ответа

```json
{
  "company": {
    "ОГРН": "...", "ИНН": "...", "КПП": "...",
    "НаимСокр": "...", "Статус": "Действующая"
  },
  "data": {
    "ЗапВсего": 12,
    "СтрВсего": 1,
    "СтрТекущ": 1,
    "Записи": [
      {
        "Номер": "78230014230101008522",
        "ВидПроверки": "Плановая",
        "ДатаНач": "2023-03-01",
        "ДатаОконч": "2023-03-30",
        "Орган": "Роструд",
        "Цель": "Соблюдение трудового законодательства",
        "Результат": "Нарушений не выявлено"
      }
    ]
  },
  "meta": { "status": "ok", "today_request_count": 1, "balance": 1000 }
}
```

## Поля ответа

| Поле | Описание |
|------|----------|
| `data.ЗапВсего` | Общее количество проверок |
| `data.Записи[].Номер` | Номер проверки |
| `data.Записи[].ВидПроверки` | `Плановая` или `Внеплановая` |
| `data.Записи[].ДатаНач` | Дата начала проверки |
| `data.Записи[].ДатаОконч` | Дата окончания проверки |
| `data.Записи[].Орган` | Надзорный орган |
| `data.Записи[].Цель` | Цель проверки |
| `data.Записи[].Результат` | Результат проверки |
