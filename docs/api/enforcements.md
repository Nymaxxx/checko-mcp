# /enforcements — Исполнительные производства (ФССП)

Исполнительные производства, открытые в отношении организации, по данным Федеральной службы судебных приставов.

Метод присутствует в API с версии 2.0.

## Запрос

```
GET https://api.checko.ru/v2/enforcements?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/enforcements?key=API_KEY&ogrn={ОГРН}&sort=-date
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации |
| `inn` | string | один из | ИНН организации |
| `sort` | string | нет | Сортировка по дате: `date` — по возрастанию, `-date` — по убыванию |
| `limit` | integer | нет | Записей на страницу (по умолчанию и максимум — 100) |
| `page` | integer | нет | Номер страницы |

> Необходимо указать `ogrn` или `inn`.

## Формат ответа

```json
{
  "company": {
    "ОГРН": "XXXXXXXXXXXXX",
    "ИНН": "XXXXXXXXXX",
    "НаимСокр": "ООО «Тестовая Компания»"
  },
  "data": [
    {
      "Номер": "XXXXX/XX/XXXXX-ИП",
      "Дата": "2024-03-14",
      "ПредметИсп": "Взыскание задолженности",
      "СуммаДолг": 1500000.0,
      "Остаток": 1200000.0,
      "ИспДок": { "Тип": "...", "Номер": "...", "Дата": "..." },
      "ОСП": { "Наим": "...", "Адрес": "..." }
    }
  ],
  "meta": { "status": "ok", "today_request_count": 1, "balance": 1000 }
}
```

## Ключевые поля

| Поле | Описание |
|------|----------|
| `Номер` | Номер исполнительного производства |
| `Дата` | Дата возбуждения |
| `ПредметИсп` | Предмет исполнения — за что взыскивают |
| `СуммаДолг` | Сумма долга, руб. |
| `Остаток` | Непогашенный остаток, руб. |
| `ИспДок` | Исполнительный документ: тип, номер, дата |
| `ОСП` | Отдел судебных приставов |

## Как интерпретировать

Открытое исполнительное производство — более сильный сигнал, чем арбитражный иск: иск это лишь заявленное требование, которое может быть отклонено, а производство означает, что решение вступило в силу и добровольно не исполнено.

Смотрите на `Остаток`, а не только на `СуммаДолг`: близкий к нулю остаток означает, что долг практически погашен. Значимы также количество производств и их накопление во времени — систематические взыскания говорят о проблемах с платёжной дисциплиной, даже если каждая сумма невелика.

Проверяйте вместе с [`/legal-cases`](legal-cases.md): иск показывает требование, исполнительное производство — неисполненное решение.
