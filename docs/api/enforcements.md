# /enforcements — Исполнительные производства (ФССП)

Исполнительные производства, открытые в отношении организации, по данным Федеральной службы судебных приставов.

Метод присутствует в API с версии 2.0.

## Запрос

```
GET https://api.checko.ru/v2/enforcements?key=API_KEY&inn={ИНН}
GET https://api.checko.ru/v2/enforcements?key=API_KEY&ogrn={ОГРН}&sort=-date
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|:------------:|----------|
| `key` | string | да | API-ключ |
| `ogrn` | string | один из | ОГРН организации |
| `inn` | string | один из | ИНН организации |
| `sort` | string | нет | Сортировка по дате: `date` — по возрастанию, `-date` — по убыванию |
| `limit` | integer | нет | Записей на страницу (по умолчанию и максимум — 100) |
| `page` | integer | нет | Номер страницы |

> Необходимо указать `ogrn` или `inn`.

## Ключевые поля

Сводные показатели по всем производствам — их достаточно для оценки риска, выгружать все записи не нужно:

| Поле | Описание |
|------|----------|
| `ОбщКолич` | Общее количество производств |
| `ОбщСум` | Общая сумма долга, руб. |
| `ОстЗадолж` | Общий непогашенный остаток, руб. |
| `ЗапВсего`, `СтрВсего`, `СтрТекущ` | Всего записей, страниц, текущая страница |

Поля записи в `Записи[]`:

| Поле | Описание |
|------|----------|
| `ИспПрНомер`, `ИспПрДата` | Номер и дата возбуждения исполнительного производства |
| `ИспДокТип`, `ИспДокНомер`, `ИспДокДата` | Исполнительный документ, на основании которого возбуждено |
| `ПредмИсп` | Предмет исполнения — за что взыскивают |
| `СумДолг` | Сумма долга по производству, руб. |
| `ОстЗадолж` | Непогашенный остаток, руб. |
| `ДолжНаим`, `ДолжАдрес` | Должник |
| `СудПристНаим`, `СудПристАдрес` | Отдел судебных приставов |

## Как интерпретировать

Открытое исполнительное производство — более сильный сигнал, чем арбитражный иск: иск это лишь заявленное требование, которое может быть отклонено, а производство означает, что решение вступило в силу и добровольно не исполнено.

Смотрите на `ОстЗадолж`, а не только на `СумДолг`: близкий к нулю остаток означает, что долг практически погашен. Значимы также количество производств и их накопление во времени — систематические взыскания говорят о проблемах с платёжной дисциплиной, даже если каждая сумма невелика.

Проверяйте вместе с [`/legal-cases`](legal-cases.md): иск показывает требование, исполнительное производство — неисполненное решение.
