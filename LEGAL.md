# Правовая информация

## 1. Характер предоставляемых данных

Checko MCP Server является программной оберткой над API сервиса Checko.ru и не хранит никаких данных самостоятельно. Все сведения поступают из государственных реестров и официальных источников:

- **ЕГРЮЛ** — Единый государственный реестр юридических лиц (ФНС России)
- **ЕГРИП** — Единый государственный реестр индивидуальных предпринимателей (ФНС России)
- **ГИР БО ФНС** — Государственный информационный ресурс бухгалтерской отчётности
- **Росстат** — данные финансовой отчётности организаций
- **Картотека арбитражных дел** — сведения об арбитражных делах
- **Реестр ФАС** — реестр недобросовестных поставщиков
- **ЕФРСФДЮЛ (Федресурс)** — Единый федеральный реестр сведений о фактах деятельности юридических лиц
- **ЕФРСБ** — Единый федеральный реестр сведений о банкротстве

Указанные сведения являются публично раскрытыми в соответствии с требованиями законодательства Российской Федерации.

## 2. Персональные данные (152-ФЗ)

Часть сведений, возвращаемых API, может относиться к персональным данным физических лиц (имена руководителей, учредителей, ИНН физических лиц и др.).

В соответствии с **Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных»**:

- Обработка персональных данных допускается только при наличии законного основания (согласие субъекта, исполнение договора, законный интерес оператора и др. — статья 6 152-ФЗ).
- Сведения из ЕГРЮЛ и ЕГРИП, раскрываемые в порядке, установленном Федеральным законом от 08.08.2001 № 129-ФЗ «О государственной регистрации юридических лиц и индивидуальных предпринимателей», обрабатываются на основании норм об обработке общедоступных персональных данных (статья 8 152-ФЗ).
- Пользователь самостоятельно определяет правовое основание обработки получаемых персональных данных применительно к своей деятельности и несёт полную ответственность за соответствие этой деятельности требованиям 152-ФЗ.

**Запрещается** использовать данный инструмент для:
- массового автоматизированного сбора персональных данных физических лиц без законного основания;
- создания баз данных физических лиц для профилирования, слежки или иных целей, не соответствующих требованиям 152-ФЗ;
- передачи персональных данных третьим лицам в нарушение применимого законодательства.

## 4. Условия использования Checko.ru API

Данный программный продукт использует API сервиса Checko.ru. Пользователь обязан:

1. Самостоятельно получить API-ключ на сайте [checko.ru](https://checko.ru/user/account/api).
2. Ознакомиться с актуальными условиями использования API Checko.ru и соблюдать их.
3. Не передавать свой API-ключ третьим лицам.
4. Соблюдать установленные Checko.ru ограничения на количество запросов.
